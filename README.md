# Student Performance Analysis

## About the Project

This is a small data analysis project I made while learning Python, Pandas, and Matplotlib.

I used student data to explore math grades, weekly study time, and absences. I also practiced filtering data, using loops, writing functions, and creating charts.

## Dataset

I used the Student Performance dataset from the UCI Machine Learning Repository.

- **File:** `student-mat.csv`
- **Number of students:** 395
- **Final grade column:** `G3`
- **Grade range:** 0 to 20

Dataset source: [UCI Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student+performance)

## Questions I Explored

- What do students' final math grades look like?
- Which study-time group has the highest average final grade?
- How do grades compare between students with different numbers of absences?

## Tools and Skills

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Data filtering and grouping
- Basic functions and loops
- Data visualization

## What I Found

- Students who studied 5 to 10 hours per week had the highest average final grade, at 11.40.
- Students who studied more than 10 hours per week had an average grade of 11.26.
- Students with more than 5 absences had an average grade of 10.84.
- Students with 5 or fewer absences had an average grade of 10.17.

These results show differences between the groups, but they do not prove that study time or absences directly affect grades.

## How to Run

1. Download or clone this repository.
2. Make sure `student-mat.csv` is in the same folder as the notebook.
3. Open `student-performance-analysis.ipynb` in Jupyter Notebook.
4. Run the cells from top to bottom.
